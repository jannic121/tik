Routing & retention

    

      
    

  

  

    Control where each recorder sends its recordings, and how long the recorder
    keeps its copy after a confirmed upload. The global default applies to any
    backend without its own rule. Recorder copies are only ever deleted after the
    file is verified present on storage — the only copy is never removed.
    Colocated backends are never deleted from (recorder and storage share a disk).
  

  







  

    
Cloud archive

    

  

  

    The optional 3rd hop: after a recording is transcribed, push it to any cloud
    (S3, Cloudflare R2, Wasabi, Backblaze B2, Dropbox, or end-to-end-encrypted Filen)
    via rclone. The control plane SSHes to the storage server, writes the rclone config,
    and restarts the service. A local copy is only ever deleted after the upload is
    verified present on the remote.

Update control plane

      

        Upload the latest tt-recorder.zip to /root on this host, then click Update.
        It verifies the archive, backs up the current files, unzips over the control plane's directory,
        and restarts it. The dashboard reconnects automatically.
      

      

      
    


    

      
Run control plane as a service

      

        Installs a systemd service so the control plane auto-restarts if it's
        ever killed (e.g. by the out-of-memory killer) and is protected from being the OOM victim
        (OOMScoreAdjust=-800). Needs the control plane to be running as root; if not, this
        shows the exact commands to run by hand. Once installed, the Update button above uses it for clean restarts.

Disk eviction

    

    
    

      
      
    

    
    

      Only the .mp4 is evicted, and only after it's verified on the cloud. Transcripts
      and chat logs are always kept on disk (so search keeps working). Oldest first;
      uses this server's saved SSH credentials — no cloud credentials needed.

    

      Age-based retention (lifecycle)
      

        
        
      

      
      
Age-based, independent of disk pressure. Both keep the transcript + chat forever.
